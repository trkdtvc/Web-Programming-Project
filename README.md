# Web Programming Project

A full-stack web application project developed to demonstrate core web programming concepts, including frontend interfaces, backend logic, and database interaction.

## Features
- Dynamic data rendering on the frontend
- Backend API endpoints for data operations
- Database connectivity and CRUD functionality
- Structured separation between frontend and backend logic

## Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Purpose
Built as a comprehensive practice project to strengthen understanding of full-stack web development, including client–server communication, backend services, and database-driven applications.
